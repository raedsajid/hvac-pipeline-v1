BuildERP now runs as a Python application.

1. Install Python 3.12.
2. Follow README.md to create a virtual environment and install requirements.txt.
3. Copy .env.example to .env and set SETTINGS_SECRET.
4. Run: python run.py
5. Open: http://127.0.0.1:8000

The first account becomes owner. Add your Gemini key in Settings.
